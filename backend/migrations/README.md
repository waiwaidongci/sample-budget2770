Schema v2 (overlapping-label audience workbook) is defined by the SQLAlchemy models and created at startup via Base.metadata.create_all. Tables: campaigns, audience_members, audience_locks, audience_selections, validation_batches, validation_reports, audience_unblinds, budget_decisions, audits, users. v1 tables from the earlier sample-size build are not reused; drop the named db-data volume before first start if it contains v1 data. For this local small application no destructive migration is run.
